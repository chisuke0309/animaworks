### 例：Notion DB 更新時のスキーマ確認漏れ

## X自動投稿：フォロワー増加には至らなかった（2026-05-01）

- **原因**: コンテンツ品質・フォーマット改善（短文・感情フック・画像）を試みたが、アカウント認知の立ち上げ自体が不足。自動化より先にアカウントの種まき（リプライ・相互フォロー等）が必要だった可能性。
- **改善**: 次に自動投稿を活用する場合、まず手動で最低100〜200フォロワーを獲得してから自動化に移行する。または対象テーマ・アカウント設計を変えて再試験する。
- **日付**: 2026-05-01

## X API impressions取得のプレースホルダー不一致（2026-04-30）

- **原因**: x_post_log.mdのmetrics列プレースホルダーが `—`（全角ダッシュ U+2014）なのに、コードが `"-"`（半角ハイフン）しか判定していなかった。
- **改善**: ログファイルのプレースホルダー文字を定数化する。読み取り側は両方を許容する。
- **日付**: 2026-04-30
