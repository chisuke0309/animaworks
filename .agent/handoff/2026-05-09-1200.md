## 5/9 真因調査の要点（重要・後続セッションへの引き継ぎ）

### 事実誤認の起点（5/8 14:03）

chiro 報告：

> 1. Claude Opus 4.7 + Anthropic × SpaceX コンピュート提携
> 公開日: 05-04 | 出典: <https://www.anthropic.com/news/claude-opus-4-7>
> ビジネス影響: API レート制限が2倍に拡大、エンタープライズ向けのサービス安定性向上

問題：

- 「容量を大幅拡大」と「レート制限が2倍」を併記し、**両者の関係が曖昧**
- 出典URL `claude-opus-4-7` は**実在しない推測URL**（正しくは `higher-limits-spacex`）
- 1記事=1主張ルール違反（Opus 4.7 リリースと SpaceX 提携を統合）

### 誤認の決定打（5/9 09:56）

judge 1回目: suggestion = 「Claudeの**利用枠**が2倍に」（正しい）
judge 2回目: suggestion = 「Claudeの**記憶量**が2倍／長い資料も一度で処理できる」（**ハルシネーション**）

判明：judge（Opus 4.7）が topic + overlay_texts の情報だけから「Claude が2倍 → きっと記憶量だろう」と推測で suggestion を生成。chiro 報告も出典URLも見ていない。

### 対策（実装済み）

1. judge プロンプトに「suggestion で固有名詞・数値・対象語を変えない」原則を追加
2. judge に `factual_claims` / `source_urls` を入力できるように拡張
3. maru/injection.md にAIニュース系では judge に必須で渡すルールを仕込み
4. chiro/tama に事故事例として永続記録

### 残るリスク

- judge プロンプトの効果は未検証（実 LLM テスト未実施）
