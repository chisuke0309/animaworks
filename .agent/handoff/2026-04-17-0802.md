## コンテンツパイプライン（確定）

### アーキテクチャ

```
【素材生成（人間・月1〜2回）】
FLUX + LoRA → 鏡花の静止画（顔固定）
    ↓
Wan 2.2 i2v → 動画化（LoRA不要。入力画像から顔を引き継ぐ）
    ↓
素材プール（asset_pool.json）にストック

【日次投稿（Anima自動）】
rin: 型選択・変数生成（テロップ・caption）
    ↓
sumi: 素材プールからクリップ選択 → テロップ合成 → BGM追加 → TikTok投稿
```

### 重要な設計判断
- **LoRAはFLUX（静止画）でのみ使用**。動画エンジンは入力画像から顔を引き継ぐためLoRA不要
- **動画エンジンは差し替え可能**（Wan / Kling / Luma）。エンドポイントURLを変えるだけ
- **素材は人間が作って貯める。毎日の組み立てと投稿だけ自動化する**（記事の教訓と同じ）
- 素材生成の初期コスト: ~$33（4シーン×20バリエーション）、以降の日次コスト: $0

### 役割分担

| 工程 | 担当 | 理由 |
|------|------|------|
| 素材生成（画像・動画） | 人間 | 品質判断・リトライが必要 |
| プロンプト案の量産 | AI → 人間がレビュー | 叩き台はAI、最終判断は人間 |
| 日次の組み立て（テロップ合成・BGM・投稿） | Anima | 定型作業・毎日やる |

## Wan i2v テンプレート（確定）

エンドポイント: `fal-ai/wan/v2.2-a14b/image-to-video/lora`
コスト: $0.10/秒

```json
{
  "image_url": "{{FLUX生成画像のURL}}",
  "prompt": "{{シーン別のモーション指示}}",
  "num_frames": 81,
  "frames_per_second": 16,
  "resolution": "720p",
  "aspect_ratio": "auto",
  "num_inference_steps": 27,
  "enable_safety_checker": true,
  "enable_output_safety_checker": false,
  "enable_prompt_expansion": false,
  "acceleration": "regular",
  "guidance_scale": 3.5,
  "guidance_scale_2": 4,
  "shift": 5,
  "interpolator_model": "film",
  "num_interpolated_frames": 1,
  "adjust_fps_for_interpolation": true,
  "video_quality": "high",
  "video_write_mode": "balanced",
  "loras": []
}
```

num_framesはシーン秒数に応じて調整（3秒=48, 4秒=65, 5秒=81）。
