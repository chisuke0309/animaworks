## 試したこと・結果

### ✅ 成功したアプローチ
- **手動 `execute_pending_posts`**：cicchi が active_hours 外でも人間側から直接ツールを叩けば投稿実行可能
- **死にコード整理はサーバーログで検証**：`Discovered personal tools` の有無で personal tool load 状態が即確認できた
- **ダミーファイルでの cancel テスト**：slot=`__test_slot__` でダミー作成→削除確認することで、本番 pending に影響なくロジック検証できた
- **HTTPS push へのフォールバック**：SSH が詰まっても HTTPS + token で通ることを実証

### ❌ 失敗・気づき
- **`git push fork main` が SSH 経由で無限停止**：BatchMode=yes でも解消せず
- **複数の古い SSH プロセスが multiplexing で残骸化**：10:31PM の古い `git-upload-pack` が生きたまま新規 push を阻害していた疑い
- **cicchi の personal tool と core tool の名前衝突**：`discover_personal_tools()` は `TOOL_MODULES` との衝突はガードするが、**personal tool の `get_tool_schemas()` が返すツール名**との衝突はガード無し＝潜在バグ
- **inbox_watcher が active_hours 外で intent filter により defer**：緊急メッセージが翌朝まで処理されない仕様
