**症状**: ニッチ65（ダックス×腰）が4/28 approvedのまま3日間投稿されずに残存。

**根本原因**: `execute_pending_posts` は同slotのapprovedを oldest-first で1件だけ実行する設計。複数approvedが積み上がると古いものしか実行されない。

- 既存approvedがある場合、新規保存を強制 `pending`（人間レビュー待ち）に変更
- commit: `adad38f2` / push: fork/main

### 2. X API impressions取得 401問題を解決

**症状**: `update_engagement` が常に「All metrics up to date」を返し、impressionsが更新されない。

**根本原因**: x_post_log.mdの metrics列プレースホルダーが `—`（U+2014 全角ダッシュ）なのに、コードが `"-"`（半角ハイフン）しか見ていなかった。APIは正常・認証も正常だった。

**修正内容** ([core/tools/x_post.py](core/tools/x_post.py)):

- 条件を `"-"` → `"-"` or `"—"` に拡張（1行修正）
- 修正後に即実行 → 12件分のimpressions取得・更新済み
- commit: `1a0e7245` / push: fork/main
