## 試したこと・結果

- ✅ novita.aiはLoRA学習機能なし（Model APIs/Agent Sandbox/GPUs構成）→ fal.aiに切り替え
- ✅ NanoBananaPro（Gemini 3 Pro）で顔生成 → 参照画像方式で一貫性確保

- ❌ similarity 高すぎ（0.55+）→ 嫁さんに似すぎる問題

## 鏡花画像生成 標準JSON（fal.ai）

```json
{
  "prompt": "kyoka, [シーン・表情の指示], sharp intense gaze, piercing eyes, fierce expression, strong eye contact, mysterious dangerous aura, high cheekbones, defined jawline, black kimono with gold peony embroidery, ultra-realistic, photographic, 8K",
  "negative_prompt": "soft expression, gentle, smiling, warm, cartoon, anime, blurry, watermark",
  "loras": [
    {
      "path": "https://v3b.fal.media/files/b/0a966fb0/hxvTK_oyDRAWRd_JLOMQH_pytorch_lora_weights.safetensors",
      "scale": 1.5
    }
  ],
  "image_size": {
    "width": 576,
    "height": 1024
  },
  "num_inference_steps": 28,
  "guidance_scale": 3.5,
  "num_images": 1
}
```

- `scale: 1.5` 固定
- `576×1024` = 9:16（TikTok縦型）
- promptの `[シーン・表情の指示]` 部分だけ差し替えて使う
